How to Set Up Your Innotech Diamond Email Signature

You only need to do this once. After that, Outlook adds your signature to every new email and every reply for you. If you get stuck at any step, the HR team will be glad to help.

Not sure which Outlook you have? Look at the top-left corner of the Outlook window. If you can see a File tab, you have classic Outlook. If there is no File tab, you have the new Outlook.

Classic Outlook for Windows

  1. 1

    Copy your signature

    Fill in your details at the top of this page and select Copy Email Signature. A green message confirms that it has been copied.

  2. 2

    Open Outlook's signature settings

    In Outlook, select File, then Options. In the window that opens, select Mail on the left, then the Signatures… button.

  3. 3

    Create a new signature

    Select New, type Innotech Diamond as the name, and select OK.

  4. 4

    Paste your signature

    Click inside the large Edit signature box and press Ctrl + V. Your complete signature appears, with the logo. If a small paste menu pops up, choose Keep Source Formatting.

  5. 5

    Make it your default

    On the right, under Choose default signature, set both New messages and Replies/forwards to Innotech Diamond.

  6. 6

    Save

    Select OK to save your signature, then OK again to close Outlook Options.

  7. 7

    Test it

    Select New Email. Your signature is already in the message. Send the email to yourself and open it: the logo turns in the message you receive. Inside the signature settings the logo stays still, and that is normal.

New Outlook for Windows and Outlook on the web

  1. 1

    Copy your signature

    Fill in your details at the top of this page and select Copy Email Signature.

  2. 2

    Open the signature settings

    Select Settings, the gear icon at the top right of Outlook. Then choose Accounts, then Signatures.

  3. 3

    Add a new signature

    Select New signature (on some versions it is called Add signature) and type Innotech Diamond as the name.

  4. 4

    Paste and save

    Click inside the signature box and press Ctrl + V. Your complete signature appears, with the logo. Select Save.

  5. 5

    Make it your default

    Under Select default signatures, choose Innotech Diamond for New Messages and for Replies/Forwards, then select Save again.

  6. 6

    Test it

    Start a new email. Your signature is already in the message. Send it to yourself and check that the logo turns in the email you receive.

Outlook for Mac

  1. 1

    Copy, then open Signatures

    Select Copy Email Signature on this page. In Outlook, open the Outlook menu, choose Settings (on older versions, Preferences), then Signatures.

  2. 2

    Add, paste and set as default

    Select + to add a signature, name it Innotech Diamond, click in the box and press Cmd + V, then save. Choose it as the default for new messages and for replies and forwards, and send yourself a test email.

If something does not look right

The logo is not moving in the email I received (classic Outlook)

Classic Outlook sometimes turns a pasted logo into a still picture. Adding the logo with Outlook's own picture button fixes it, and your text stays as it is.

  1. Go back to File > Options > Mail > Signatures… and select Innotech Diamond.
  2. Click the logo once and press Delete. Leave the cursor where the logo was.
  3. Select the small picture icon above the edit box.
  4. In the File name box, paste the logo address and select Insert.
  5. Select OK, then send yourself a new test email.

Also check that animations are on for your PC: Windows Settings > Accessibility > Visual effects > Animation effects.

The logo is missing

Outlook downloads the logo while you paste, so the computer has to be online. Delete the signature text, check your connection, and paste again.

The font or spacing looks different

The signature was pasted with different formatting. Delete it, paste again, and choose Keep Source Formatting if a paste menu appears.

My job title or mobile number has changed

Come back to this page, update your details, copy again, and paste over your old signature in the same settings window.
